# Shiv Soul Creations - deploy on Vercel
1. Vercel > Storage > add **Neon Postgres** (sets DATABASE_URL automatically).
2. Env vars: SECRET (long random text), ADMIN_USER, ADMIN_PASS.
3. Push this folder to GitHub, import in Vercel, deploy. Tables + the 15 products are created on first visit.
4. Open /admin, log in, upload product images, add coupons, set WhatsApp / UPI / policies in Settings.
